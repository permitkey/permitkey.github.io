# PermitKey project website

This repository contains the public-facing PermitKey project page, adapted from the [Nerfies project-page template](https://github.com/nerfies/nerfies.github.io). The template and this website are licensed under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/); the PermitKey data release and research code will have separate, explicit terms.

The site is a static GitHub Pages website. The `data/` page is a status page until the aggregate release has passed source-rights, geography, disclosure, and validation review.

PermitKey currently covers 150,044,555 retained source records across 85 contributions. These are collected source records, not deduplicated unique permits. The site describes the planned jurisdiction-year-work-type and 0.1-degree grid-year-work-type products without exposing raw permit-level records.
