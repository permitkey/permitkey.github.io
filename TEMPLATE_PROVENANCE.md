# Website template provenance

PermitKey’s project page is adapted from the official Nerfies website repository:

<https://github.com/nerfies/nerfies.github.io>

The source template was cloned locally at commit `657409a62d59a93163872c0e4921cf651b987810` on September 14, 2026. The Nerfies website states that its website work is licensed under [Creative Commons Attribution-ShareAlike 4.0 International](https://creativecommons.org/licenses/by-sa/4.0/). The PermitKey page keeps that attribution in its footer. PermitKey’s future data release and research code will have separate, explicit terms.
The local `static/webfonts/` files are the Font Awesome 5.15.4 webfont subsets used by the template’s stylesheet, retrieved from the public cdnjs distribution so the icons render on GitHub Pages. Font Awesome is distributed under its [free license](https://fontawesome.com/license/free).
