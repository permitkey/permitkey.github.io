PermitKey data

Public aggregate release. This is the canonical access point for the PermitKey data, taxonomy, provenance, and validation record.

Data tables

  • Permitting jurisdiction × year × work type
  • 0.1° grid × year × work type for reliably geocoded records
  • CSV and Parquet packages with a data dictionary, taxonomy, provenance, and validation notes

The tables preserve source-record and multi-label semantics. A source occurrence may contribute to multiple work types, so each category count is read on its own work-type scale.
